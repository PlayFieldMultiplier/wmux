### Added

- **Close and keep folder.** When closing a task keeps failing, for example
  because wmux cannot confirm that everything its terminals started has
  exited, the failure now offers Close and keep folder. It closes the task
  and leaves its folder on disk as it is, and tells you where. It is offered
  in the task's diff, in Fleet, in the sidebar's Close finished tasks and in
  the task cleanup list. Bots can do the same with `task_close` and
  `keep_folder: true`. (#2425)

### Fixed

- **Closing a task on Windows removes its folder the first time.** If the
  task's terminal had started something that was still running, such as an
  agent or a tool, the first close failed with "Permission denied", and a
  second close left the task's folder behind. Closing a task now stops
  everything its terminals started and checks that it all exited before the
  folder is removed. A half-removed folder is finished later, and only when it
  is safe to do so; if wmux cannot confirm that everything stopped, it keeps
  the folder and tells you why. No new terminal can open in a folder while its
  removal is unfinished. If the task's repository has been moved or deleted,
  closing the task keeps the folder and says where it is, instead of failing
  every time. Stopping a bot's worker also stops everything that worker
  started. (#2388)
