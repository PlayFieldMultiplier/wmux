### Added

- **Bots' Codex workers use their connections too.** When a bot's workers run on Codex, a task's connections reach them with the same tool rules as on Claude Code. Codex cannot send a key in another header as `Bearer`, nor reach SSE servers, so a task with such a connection is refused for Codex workers. (#2210)

### Changed

- **A bot's Codex workers load only wmux and the connections you give bots.** Your own Codex MCP servers, ChatGPT apps and plugins are turned off for them. (#2210)
