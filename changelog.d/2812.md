### Changed

- **Unattended bot workers run inside a fence.** A bot worker in Bypass or Auto mode now writes only inside its task folder and its own temp folder, cannot read named credential files or wmux's own secrets, and runs its commands in the OS sandbox where the computer has one (macOS; Linux with bubblewrap); elsewhere it gets the file guard and the credential denies and its pane says the fence is weaker. Settings → Roles & fan-out can turn the fence off per workspace. (#2812)
