### Fixed

- **A renamed process no longer passes as a live agent.** Before wmux delivers a scheduled or queued prompt into a pane, it checks that the pane's agent is still running. That check used the process's name and command line, which any program can set for itself, so `exec -a claude sleep` or `node /tmp/claude.js` read as Claude. On macOS and Linux, wmux now also checks the executable the system reports for the process: the agent's own binary, or a runtime running a script from inside the agent's installed package. Windows is unchanged.
