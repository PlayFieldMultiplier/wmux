### Changed

- **A bot's worker can label pull requests.** It may now run
  `gh pr edit <number> --add-label <labels>` and/or `--remove-label <labels>`,
  alone on the line. Before, every `gh pr edit` was refused, even adding a
  label to its own pull request. Every other edit, merging, its own pushes,
  `gh api` writes and anything chained to the label command are still
  refused. A WSL pane's worker cannot label yet.
