### Added

- **Rewind on the agent toolbar.** When the focused pane runs Claude Code, the
  agent toolbar now has a Rewind button that opens Claude's own Rewind picker,
  the same action as Rewind… in the pane tab menu. It is greyed out while
  Claude is working, and when Claude can't take it yet (text in its input, a
  prompt on screen) it says why, as the menu does. Before, Rewind was only in
  the pane tab menu.
