### Fixed

- **Scrollback, bot room and Codex thread files survive a brief lock on
  Windows.** When an antivirus scan or another reader held one of these files
  for a moment, saving it failed on the spot, and a scrollback or bot room save
  that failed this way could leave the file missing until the next save. wmux
  now waits briefly and tries again, and if the save still fails it puts the
  previous version back, as it already did for its JSON state files. (#2783)
