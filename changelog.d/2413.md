### Fixed

- **A WSL pane inside a git repository shows its branch.** The branch watcher
  runs on the Windows side and was given the pane's Linux path, which names
  nothing there, so the header and pane metadata stayed empty. It now reads the
  same directory through its Windows name (`D:\…` for a drive mount,
  `\\wsl$\<distro>\…` inside the distro), without running git. (#2413)
