### Fixed

- **Panes outside a git repo no longer run `git` every five seconds.** The
  branch lookup that feeds the pane header had no memory of "not a repo", so
  a pane sitting in your home directory spawned `git` on every poll tick for
  as long as the app ran — one more process per such pane every five seconds,
  in the process that also moves your terminal output. The answer is now
  remembered per directory (a minute for "not a repo", 15 s for a branch), so
  the poll is free for those panes. (#2392)
