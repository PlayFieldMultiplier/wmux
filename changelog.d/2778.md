### Fixed

- **Long GitLab squash messages and queries no longer fail on Windows.** wmux's GitLab writes (opening and squash-merging a merge request) and its GitLab GraphQL reads now send their fields to `glab` as JSON on standard input instead of the command line. A long value no longer fails with `spawn ENAMETOOLONG` before GitLab CLI starts. (#2778)

### Changed

- **GitLab squash commits now keep the body.** Squash-merging a GitLab merge request from wmux used to keep only the subject line. It now keeps the body too, after a blank line, as the GitHub merge already did. (#2778)
