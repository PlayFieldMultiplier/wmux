### Changed

- **`task_push` and `task_fetch` run their network git in a git dir wmux
  owns.** Each push, fetch and ls-remote for a task runs in a fresh, empty git
  dir under wmux's data folder, on the repository wmux recorded when it
  started the task, so only your system and global git config apply to it.
  Before main sets `origin/<branch>`, it checks the ref's path. `task_push`
  no longer writes `branch.<name>.remote` and `branch.<name>.merge`; workers
  open the pull request with `gh pr create --head <branch>`. A task of your
  own started before this update cannot push or fetch; start it again. (#2337)
