### Added

- **`npm run changelog:check` checks the changelog.d fragments.** It reports
  what a release fold would get wrong as errors: an empty fragment, a section
  Keep a Changelog does not have, a `##` or `####` heading, text the fold
  drops, an empty section, a duplicated entry, or "see below" with nothing
  below it. The README's style rules and PR numbers missing from local git
  history are warnings. Before, such mistakes surfaced only in the published
  release notes. (#2348)
