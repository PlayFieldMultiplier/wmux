### Fixed

- **A pane interrupted with Esc goes Idle right away.** When Esc stopped a
  Claude Code tool call, the sidebar could keep the pane Running for up to two
  minutes. This happened when the Claude hooks had no prompt-submit hook, or
  when there were no hooks at all. The pane now goes Idle as soon as Claude
  Code prints its "Interrupted" row. A pending approval still stays on screen.
