### Fixed

- **No more "needs you" toasts while Claude is still working.** Claude Code
  reports every permission dialog it is about to show, including ones nobody
  sees — a permission its mode resolves on its own, a background agent's
  request, a dialog you answered within a second. Each report used to become
  a toast about 1.5 s later, so a busy pane could nag every couple of seconds
  with nothing to answer. wmux now looks at the pane's screen before it
  confirms the alert, looks once more a moment later, and stays quiet only
  when no dialog is there both times. A dialog that is really up still
  alerts as before, and an alert stands down if you answer or the turn ends
  while wmux is looking. The phone's pending card is unchanged: it still
  appears at once and clears when the dialog is gone. (#2390)
