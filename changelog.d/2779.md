### Fixed

- **Starting the daemon right after it crashed no longer refuses on Windows.**
  A start that ran while the old daemon was still shutting down could see it
  as running, then fail to read it, and treat it as a live daemon it could
  not verify. `wmux daemon start` refused with "alive but image lookup
  failed", and the app asked whether to clean up. wmux now asks Windows
  whether that process has already exited. A daemon that has exited is
  cleaned up and a new one starts. A daemon that is still running is checked
  as before. (#2779)
