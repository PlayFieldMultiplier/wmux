### Fixed

- **The Git page and repo lookup now only open local folders.** A folder on a
  network share, including one reached through a link or a mapped network
  drive, is no longer read by the Git page, the file tree or the previews; a
  WSL distro's folders still work. A pane's folder also follows only local
  folders: a working-directory report from another host, such as an `ssh`
  session inside the pane, no longer moves it. (#2491)
