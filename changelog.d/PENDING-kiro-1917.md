### Fixed

- **Kiro hooks run on Windows.** The documented Kiro hook line, `node "<path>"`, never ran on Windows. Kiro hands the line to `cmd /C` in a way that passes the quotes on to `node`, so every hook failed for every path, and Kiro panes fell back to screen detection. On Windows the hook line is now `node <path>/wmux-kiro-bridge.mjs`, unquoted and with forward slashes, so the folder holding the hook files must have no spaces (for example `C:/wmux-hooks/`). A Windows `~/.kiro/agents/wmux.json` written from the old instructions needs both `command` values updated. macOS and Linux keep the quoted form (#1917).
