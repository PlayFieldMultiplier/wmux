### Fixed

- **A worker on a Windows-host repository is no longer handed a WSL fetch
  line that cannot work.** `task_fetch` also returned a second line for a WSL
  shell, but the task's relay names the repository's objects by a Windows
  path, which WSL git cannot read, so that line failed with missing objects.
  The WSL line is now returned only for a repository that lives inside a WSL
  distro. (#2373)
- **Closing a task no longer times out while a fetch or push is running for
  it.** `task_close` waited for the task's relay to be removed, which waits
  for any `task_fetch` or `task_push` in progress, so the call could report a
  timeout even though the close went through. The relay is now removed in the
  background. (#2373)
