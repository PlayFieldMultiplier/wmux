### Changed

- **Lower memory for the background service, the command-line tool and the
  agent tool server.** Like the app's windows before them, their scripts no
  longer contain characters that need two bytes, so the engine stores each at
  one byte per character. The background service holds about 8 MB less, each
  agent tool server about 3 MB less, and the status line and hook scripts that
  start on every refresh about half what they did. Nothing you see changes.
  (#2760)
