# Sprint process for the org design

Owner: AO_WMUX. Victor approves scope and boundaries.

## Rules
- A sprint has one goal, a fixed list of tasks, and a definition of done (DoD) written before work starts.
- Each sprint ends with a merged PR per deliverable, each with an independent review on its exact head.
- Scope is cut, not extended. Anything not done moves to the next sprint with a note.
- No agent is launched, moved or closed by a sprint unless Victor approved that launch in writing.
- Every sprint writes its result to `docs/org/LEDGER.md` with evidence.

## Sprint 1 (conventions and process)
Goal: fix the conventions every later agent must follow, so new agents start from one written standard.
Tasks: (a) this file; (b) `docs/org/conventions/AGENT-CONVENTIONS.md`; (c) ledger rows.
DoD: both files merged; each rule names its source or is marked as a proposal; reviewed on its head.
Out of scope: launching, the registry file, any agent profile.
